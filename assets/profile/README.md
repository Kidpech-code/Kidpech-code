# Profile artwork

These are the original decorative SVGs used by the profile, saved locally without changing their artwork. The capsule header/footer, typing animation, badges, stack icons, and contact icons keep the existing visual style. Animation and embedded fonts are contained in the SVG files.

`sources.json` records their original source URLs for attribution and deliberate future updates. The sources include Capsule Render, Readme Typing SVG, Shields.io, Skill Icons, GitHub Profile README Generator, and SuperTinyIcons; brand marks remain those of their respective owners.

GitHub statistics, streak, profile counters, and Spotify continue to use live endpoints in the README. The WakaTime block and all four existing workflows are preserved. Only the two unavailable statistics endpoints were replaced, using GitHub Profile Summary Cards in the existing radical theme.

Do not freeze the live widgets into snapshots or replace the profile layout when making visual refinements. Public image services and GitHub caching can still affect how quickly live data updates or whether an image loads.
